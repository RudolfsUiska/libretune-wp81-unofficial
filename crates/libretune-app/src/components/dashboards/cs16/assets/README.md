# CS 1.6 dash font — personal use only, do not upstream

`ArialPixel.ttf` is copied from https://github.com/ekmas/cs16.css (commit bc0cb3d),
which is MIT-licensed as a whole but does not document where the font itself
comes from or under what terms. It is bundled so the "CS 1.6" dashboard renders
offline in the owner's build. Do not include it in any contribution to LibreTune
until its licence is established; the dash falls back to Verdana/Tahoma without it.
